# 📈🐜 AntKstockTramingCamp(개미국장훈련소)🏕️
투자 초보들을 위한 훈련소입니다.
투자에 대한 감을 잡도록 도와드립니다.
투자의 기초적인 지표인 이동평균선, MACD, 볼린저 밴드 사용하여 분석합니다.

관심종목의 종가를 자동으로 수집하고
분석하여 매도/매수 추천 알림을 보내드립니다.

알고리즘이 추천하는 대로 가상자산을 운영해보세요
투자에 대한 감각을 키우실 수 있습니다.

## Key Features
 - 주식 데이터 자동 수집 및 전처리
 - 전략 기반 매수/매도 로직 및 추천 알림
 - 전략 기반 투자 이력관리
